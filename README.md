# صانعات الويب

مختبر مشروع موقع محافظة مسندم.

مختبر افتراضي لوحدة «تصميم مواقع الويب» في مادة تقنية المعلومات للصف العاشر. يحتوي على محاكي Visual Studio Code ومتصفح، ومهام عملية بالنقاط والمؤقت، واستراتيجيات تعلم نشط، ومستوى متقدم للمجيدات.

إعداد المعلمة: ابتسام الرواس، مدرسة خولة بنت حكيم للبنات (٩–١٢)

## للطالبات
افتحي الرابط، واكتبي اسمكِ وصفكِ، ثم أدخلي رمز الدرس الذي تعطيكِ إياه المعلمة. في نهاية الحصة اضغطي «النتيجة والإرسال»، وانسخي الرسالة وأرسليها للمعلمة.

## للمعلمة
- ادخلي «واجهة المعلمة» بالرقم السري.
- من تبويب «الإعدادات» أنشئي رمز الدرس لكل حصة.
- من تبويب «استيراد رسائل النتائج» الصقي رسائل الطالبات.
- تُحفظ النتائج في متصفح جهاز المعلمة فقط، فاستخدمي الجهاز والمتصفح نفسيهما دائماً، ونزّلي ملف CSV من «جدول النتائج» نسخةً احتياطية.
